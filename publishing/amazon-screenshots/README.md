# Amazon landscape feature screenshots

Upload all four PNG files, in filename order, to the Amazon Developer Console tablet Screenshots field. Each is 1920 x 1200 pixels (16:10 landscape), opaque RGB PNG, matching a size shown in the owner's console. Extract the ZIP first; upload the PNGs individually, not the ZIP.

1. 01-simple-counting.png - large silver counting button and digital display.
2. 02-color-themes.png - Emerald, Ocean and Rose; 16 themes and appearance controls.
3. 03-save-and-restore.png - actual Saved counts dialog and sample snapshots.
4. 04-optional-targets.png - actual target chooser and an optional target example.

The four designs frame actual shipping MainActivity views and AlertDialog roots from Tasbih Counter - Zikr version 1.8.0 / version code 11. Native Android rendering used Robolectric API 35; these are designed feature graphics around host-rendered UI, not physical Fire-tablet captures. Native UI images were scaled and positioned in a browser layout, not recreated by image generation. The decorative background was generated with imagegen. The ads controller was disabled only during capture: no SDK requests, impressions, pretend live banner or TEST AD fixture appears. This does not remove advertising from the APK or establish real-device/ad-serving approval.

Example counts, saved names and the selected target are demonstration data. Fresh installs still start with no target or religious presets. No application source, APK, signing key or package identity changed to create these media files. APK and source downloads remain the validated version 1.8.0 build from source commit 1337a1a64afed83c3a610f05d305c63665af839c.
